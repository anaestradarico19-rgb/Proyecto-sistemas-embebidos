# TC-014 — Operación continua de 2 horas

## Req. Trazabilidad
RNF-02

## Objetivo
Verificar la estabilidad del sistema durante operación continua de 2 horas.

## Precondiciones
Sistema completamente ensamblado y energizado.

## Resultado Esperado
El sistema opera correctamente sin reinicios ni pérdida de datos durante la prueba.

## Tipo
HIL/System

## Evidencia
Pendiente

## Estado
PASS
