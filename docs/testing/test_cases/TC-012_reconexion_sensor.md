# TC-012 — Reconexión automática del sensor

## Req. Trazabilidad
RF-12

## Objetivo
Verificar que el sistema detecta y maneja correctamente la reconexión del sensor.

## Precondiciones
Sistema operando normalmente y sensor inicialmente conectado.

## Resultado Esperado
El sistema retoma automáticamente las lecturas después de reconectar el sensor.
