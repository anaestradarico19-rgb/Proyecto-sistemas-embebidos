# TC-004 — Activación del actuador

## Req. Trazabilidad
RF-04

## Objetivo
Verificar la activación del actuador cuando la presión supera el umbral configurado.

## Precondiciones
Sistema energizado y actuador conectado.

## Resultado Esperado
El actuador cambia correctamente de estado cuando se supera el umbral.
