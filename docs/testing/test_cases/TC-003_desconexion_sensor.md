# TC-003 — Detección de desconexión del sensor

## Req. Trazabilidad
RF-03

## Objetivo
Verificar que el sistema detecta la desconexión del sensor y registra el error.

## Precondiciones
Sistema operando con sensor conectado.

## Resultado Esperado
El sistema registra un mensaje ERROR al desconectar el sensor.

## Tipo
HIL/System

## Evidencia
Pendiente

## Estado
Pendiente
