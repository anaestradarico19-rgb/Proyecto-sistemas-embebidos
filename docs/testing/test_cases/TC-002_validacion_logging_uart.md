# TC-002 Validación de Logging UART

## Trazabilidad de Requerimiento
RF-002

## Objetivo de la Prueba
Validar que el sistema registra eventos mediante UART.

## Precondiciones
- Sistema energizado
- Monitor serial activo

## Resultados Esperados
El sistema debe mostrar mensajes INFO, WARN y ERROR.
