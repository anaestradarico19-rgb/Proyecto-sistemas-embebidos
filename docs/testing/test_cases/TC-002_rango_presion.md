# TC-002 — Validación de rango de presión

## Req. Trazabilidad
RF-02

## Objetivo
Verificar que las lecturas del sensor permanecen dentro del rango válido definido.

## Precondiciones
Sistema operando normalmente.

## Resultado Esperado
Las lecturas se encuentran dentro del rango permitido.

## Tipo
HIL/System

## Evidencia
Pendiente

## Estado
En validación
