# TC-010 — Registro de eventos en log

## Req. Trazabilidad
RF-10

## Objetivo
Verificar que el sistema registra eventos relevantes, cambios de estado y errores mediante logging.

## Precondiciones
Monitor serial activo y sistema operando.

## Resultado Esperado
El sistema registra correctamente eventos INFO, WARN y ERROR.

## Tipo
HIL/System

## Evidencia
Pendiente

## Estado
Pendiente
