# TC-013 — Tiempo de respuesta menor o igual a 2 segundos

## Req. Trazabilidad
RNF-01

## Objetivo
Verificar que el tiempo de actualización del sistema es menor o igual a 2 segundos.

## Precondiciones
Sistema operando correctamente y GUI activa.

## Resultado Esperado
El sistema actualiza los datos en un tiempo menor o igual a 2 segundos.

HIL/System
