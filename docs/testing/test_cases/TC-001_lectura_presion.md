# TC-001 — Lectura válida de presión

## Req. Trazabilidad
RF-01

## Objetivo
Verificar que el sistema adquiere y muestra correctamente la presión atmosférica en hPa.

## Precondiciones
Sistema energizado y sensor conectado mediante I2C.

## Resultado Esperado
La lectura de presión se muestra correctamente y permanece dentro del rango esperado.

## Tipo
HIL/System

## Evidencia
Pendiente

## Estado
PASS
