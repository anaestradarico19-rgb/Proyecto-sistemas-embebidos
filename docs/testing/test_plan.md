# Plan de Pruebas

## Objetivo
Validar el correcto funcionamiento del sistema embebido.

## Tipos de Pruebas
- Pruebas unitarias
- Pruebas de integración
- Pruebas de sistema

## Estrategia de Validación
Cada requerimiento debe tener:
- Caso de prueba asociado
- Evidencia objetiva
- Resultado PASS o FAIL
