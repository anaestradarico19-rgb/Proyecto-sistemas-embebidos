# Análisis de Riesgos Técnicos

| Riesgo | Impacto | Mitigación |
|---|---|---|
| Fallo de integración BMP280 | Alto | Evaluación de sensor alternativo |
| Fallo comunicación I2C | Alto | Validación de direcciones y conexiones |
| Retraso en validación del sensor | Medio | Uso de sensor compatible BME280 |
