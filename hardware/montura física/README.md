# Montura Física del Sistema

## Descripción General

La montura física del sistema fue diseñada específicamente para alojar los componentes electrónicos del manómetro ambiental basado en ESP32.

La estructura fue fabricada en acrílico cortado mediante láser, utilizando un diseño personalizado ajustado a las dimensiones reales del circuito y los periféricos utilizados en el proyecto.

## Objetivos del Diseño

La montura física fue desarrollada con los siguientes objetivos:

- proteger los componentes electrónicos,
- mejorar la presentación del sistema,
- facilitar el ensamblaje,
- organizar el cableado,
- permitir acceso a botones y conexiones,
- proporcionar estabilidad mecánica durante la demostración.

## Componentes Considerados en el Diseño

La carcasa fue diseñada considerando espacio y acceso para:

- ESP32,
- pantalla OLED SSD1306,
- sensor BME280,
- LED RGB,
- buzzer,
- botón de usuario,
- sistema de alimentación.

## Fabricación

La estructura fue diseñada para corte láser en acrílico.

El diseño considera:

- dimensiones del circuito,
- separación entre módulos,
- ventilación básica,
- estabilidad física,
- acceso visual a la interfaz OLED.

## Integración Física

Los componentes electrónicos fueron integrados dentro de la montura física manteniendo organización del cableado y acceso funcional a los elementos interactivos del sistema.
